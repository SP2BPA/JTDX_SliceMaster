# v0.3g Log4OM — Advanced UI preservation hotfix

Data: 2026-09-20

## Diagnoza z pełnego logu v0.3f

Build doszedł do:
`[1213/1219] Building CXX object CMakeFiles/jtdx.dir/Configuration.cpp.obj`

Błąd:
`Ui::configuration_dialog has no member named label_11`

Upstream `Configuration.cpp::initialize_models()` wykonuje:
`ui_->label_11->setText("<a><img src=\":/decpasses.png\" height=\"464\" /></a>");`

Patcher v0.3f zastępował cały `verticalLayout_9` nowym panelem Log4OM i usuwał oryginalny `QLabel label_11`.

## Poprawka v0.3g

- zachowuje nowy panel `Log4OM 2`
- przywraca oryginalny `QLabel label_11` w tym samym `verticalLayout_9`
- zachowuje obraz / informację dekodowania używaną przez upstream JTDX
- source gate wymaga obecności `label_11`

## Zakres

Wyłącznie zachowanie istniejącego elementu UI. Bez zmian w:
- FT8 / FT2
- SuperHound
- DSP / dekoderze
- CAT / PTT
- WideGraph
- Slice Master
- logice odczytu SQLite Log4OM
