# v0.3h Log4OM — qsqlite-only MSI packaging hotfix

Data: 2026-09-20

## Stan v0.3g

Kompilacja aplikacji zakończyła się poprawnie. Przeszły również:
- audyt projektu,
- gate WiX,
- wersjonowanie MSI,
- konfiguracja CPack.

Awaria nastąpiła dopiero w `BundleUtilities/GetPrerequisites` podczas CPack.

## Diagnoza

Do instalatora był kopiowany cały katalog:

`Qt/plugins/sqldrivers`

Zawiera on m.in.:
- wymagany `qsqlite.dll`,
- nieużywany `qsqlibase.dll`.

`qsqlibase.dll` jest sterownikiem Firebird/InterBase i wymaga `fbclient.dll`. JTDX nie korzysta z Firebird, więc ta zależność jest zbędna. CPack próbował ją jednak rozwiązać i kończył błędem:

`objdump.exe: 'fbclient.dll': No such file`

## Poprawka v0.3h

Do instalatora trafia wyłącznie:

`plugins/sqldrivers/qsqlite.dll`

Builder sprawdza:
- obecność qsqlite-only install rule,
- brak instalacji całego katalogu sqldrivers,
- obecność `qsqlite.dll` w stagingu CPack,
- brak `qsqlibase.dll` i `fbclient.dll` w stagingu.

## Zakres

Wyłącznie pakowanie MSI. Bez zmian w:
- FT8 / FT2,
- SuperHound,
- DSP/dekoderze,
- Log4OM runtime logic,
- CAT/PTT,
- WideGraph/GUI,
- Slice Master.
