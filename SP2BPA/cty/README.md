# Testowy cty.dat dla JTDX

Ten plik służy do testu zewnętrznej bazy DXCC bez przebudowy JTDX.

Potwierdzone:
- zawiera wpis `=3Y0K` pod **Bouvet**,
- JTDX może użyć zewnętrznego `cty.dat` z katalogu danych użytkownika zamiast kopii wbudowanej.

Źródło kopii użytej do testu:
`boydsoftprez/NereusSDR` — `cty.dat`, gałąź `main`.

Przed użyciem zachowaj kopię obecnego `cty.dat`.
